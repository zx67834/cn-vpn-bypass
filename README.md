# VPN 国内直连

Windows 上 StrongVPN / OpenVPN 开着全局隧道时，把国内运营商网段改走当前局域网网关。国外地址仍走 VPN。

QQ、微信这类国内服务会直连。`1.1.1.1`、`8.8.8.8` 仍走隧道。

## 用法

1. 双击 `直连国内.bat`，在 UAC 提示里允许管理员权限。
2. 想恢复成全部走 VPN，双击 `取消直连.bat`。
3. 重启，或从 Wi-Fi 换成网线之后，再双击一次 `直连国内.bat`。脚本会重新识别当前网关。

路由只写在当前系统里，不做成开机永久路由。换网卡后旧的下一跳会失效，所以需要再运行一次。

## 自己的地址

复制 `extra-ips.example.txt` 为 `extra-ips.txt`，一行一个 IP 或 CIDR，然后重新双击。这个文件不会进仓库。

脚本还会固定带上这几个公共 DNS：`114.114.114.114`、`114.114.115.115`、`223.5.5.5`、`223.6.6.6`、`180.76.76.76`、`119.29.29.29`。

## 原理

OpenVPN 会加 `0.0.0.0/1` 和 `128.0.0.0/1`，流量进 TAP。这里给国内前缀加更具体的路由，下一跳是当前那块非 TAP 网卡的默认网关。TAP、ZeroTier、VirtualBox、VMware 会被跳过。

VPN 服务器自己的地址、`1.1.1.1` 和 `8.8.8.8` 不会被写进直连表，避免隧道被绕回去。

## 地址库

`cn-cidrs.txt` 是 [gaoyifan/china-operator-ip](https://github.com/gaoyifan/china-operator-ip) 里 `china.txt` 的 2026-10-10 快照，包含电信、联通、移动、教育网、广电等常用国内网段。该数据使用 MIT 许可，声明见 `LICENSE-DATA.txt`。
